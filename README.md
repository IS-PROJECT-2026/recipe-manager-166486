# Recipe Manager

Recipe Manager is a web application for discovering, searching, creating, and managing cooking recipes.
It combines a built-in recipe dataset with custom recipes stored in browser local storage, so users can browse default recipes and also add their own.

## System Description

The system includes the following core features:

- Home page that displays featured recipes from both the default dataset and custom recipes.
- Search page with text and category filtering.
- Recipe details page that shows ingredients, instructions, cooking time, and servings.
- Favorites system that allows users to add/remove recipes and view favorites in one place.
- Recipe addition form with form validation that display inline error messages.
- Edit and Delete control for custom recipes.
- A recipe rating feature allowing allowing rating from 1-5 stars.
